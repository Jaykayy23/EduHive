## Dependency remediation and remaining advisory

The clean source-only staging copy also passed `npm ci`, automatic Prisma generation, all 65 tests present at that snapshot, and a production build without a `.env` or database/auth/Stream environment secrets. This verifies installation independently of the original development checkout. Comparing its route list revealed omitted metadata icons in the packaging allowlist; a regression test and explicit icon entries were added, and the final Node suite contains 68 tests. Application icons are retained in the final archive.

Next.js and its ESLint configuration were patched from 16.3.0 to 16.4.3. Validation moved to Zod 4.6.7 with a compatible resolver; the moderation error accessor was updated and validation/form behavior checked. Tiptap packages were aligned on stable 3.32.1, preserving plain-text editor extensions and transaction-driven React updates. Unused Magic Labs UI dependency was removed. Compatible transitive patches and the nanoid override were refreshed.

The final npm audit reports **0 critical, 0 high, 0 moderate, 1 low**. The remaining finding is `deepmerge@4.3.1` via `stream-chat-react -> react-player`: [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4). The compatible automatic fix did not resolve it. Do not claim the dependency tree is vulnerability-free; track upstream remediation and rerun `npm audit` before distribution/deployment. No forced major Stream upgrade or unverified deepmerge downgrade was applied merely to change the count.
